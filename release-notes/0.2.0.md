- 完善桌面打包信息，统一应用名称、版本号和发布者。

- 可从 0.1.0 直接覆盖安装到 0.2.0。
- 覆盖安装不会主动删除用户数据目录。
- 用户数据仍保存在 `%APPDATA%/com.wang.time-manager`，包括 `time-manager.db`。
